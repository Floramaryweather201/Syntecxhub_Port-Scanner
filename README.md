# Syntecxhub Port Scanner


## Features

- Scan TCP ports on a specified IPv4 address
- Choose a custom port range
- Identify open TCP ports
- Display commonly associated service names
- Validate IP addresses and port ranges
- Save results to scan_results.txt

## Technologies Used

- Python 3
- Python socket library
- Python ipaddress module
- Visual Studio Code

## How to Run

1. Open the project folder in a terminal.
2. Run the following command:

    python3 port_scanner.py

3. Enter the target IPv4 address.
4. Enter the starting and ending ports.
5. Review the results in the terminal and scan_results.txt.
